# RazorPayClone
Project Title: Razorpay Web Interface Clone
Technologies Used: HTML5, CSS3, Tailwind CSS, PostCSS, JavaScript
Description: Developed a highly accurate, fully responsive front-end clone of the Razorpay landing page. Utilizing Tailwind CSS for modern utility-first styling and PostCSS for build optimization, the project replicates Razorpay's complex layouts, navigation structures, and interactive UI components. The application is completely optimized for all screen sizes, demonstrating strong proficiency in pixel-perfect UI development and modern responsive design workflows.
